# Navigator for Android TV / Firestick

Navigator Stremio client with Leanback + D-pad support — single universal APK (no native libs, ARM/armeabi-v7a + arm64).

## Download

[Latest release](https://github.com/adamjen/navigator-tv/releases/latest)

**On the Firestick:** open the link above in the TV browser (or any device), tap the `navigator-tv-0.1.0.apk` asset, then open the download and allow installation from unknown sources.

Built from [AyaanZaveri/navigator](https://github.com/AyaanZaveri/navigator) + Leanback/D-pad integration. Debug-signed (development keystore) — for personal use.
